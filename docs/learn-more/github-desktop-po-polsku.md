# GitHub Desktop po polsku

Ten poradnik opisuje podstawowe kroki pracy z GitHub Desktop w języku polskim.

## 1. Klonowanie repozytorium

1. Otwórz **File** → **Clone Repository…**
2. Wybierz repozytorium z listy albo wklej URL.
3. Wskaż folder lokalny i kliknij **Clone**.

## 2. Tworzenie i przełączanie gałęzi

1. Otwórz menu **Branch**.
2. Kliknij **New Branch…**.
3. Podaj nazwę gałęzi i zatwierdź.

## 3. Commit zmian

1. Przejdź do zakładki **Changes**.
2. Zaznacz pliki, które chcesz zatwierdzić.
3. Wpisz tytuł i opis commita.
4. Kliknij **Commit to \<branch\>**.

## 4. Wysyłanie zmian (push)

1. Po wykonaniu commita kliknij **Push origin**.
2. Jeśli to nowa gałąź, Desktop zaproponuje publikację.

## 5. Aktualizacja lokalnej gałęzi (fetch/pull)

- **Fetch origin** pobiera informacje o zmianach zdalnych.
- **Pull origin** pobiera i scala zmiany do lokalnej gałęzi.

## 6. Pull Request

1. Po wypchnięciu gałęzi wybierz **Create Pull Request**.
2. Uzupełnij tytuł i opis PR w GitHub.
3. Wyślij PR do przeglądu.
